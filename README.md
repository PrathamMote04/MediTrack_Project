# 💊 MediTrack — Medicine Reminder & Tracker

MediTrack is a medicine management application designed to help users organize their medicines, maintain schedules, and remember when to take their medication.

## ✨ Features

- Add and manage medicines.
- Organize medicine schedules.
- View medicine information and reminders.
- Simple and user-friendly interface.
- Built with React and Vite.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Language:** JavaScript
- **Styling:** CSS
- **Package Manager:** npm
- **Version Control:** Git and GitHub
- **CI/CD:** Jenkins
- **Build Output:** `dist/`

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the repository

```bash
git clone https://github.com/PrathamMote04/MediTrack_Project.git
```

### 2. Navigate to the project

```bash
cd MediTrack_Project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🏗️ Production Build

To create a production-ready build, run:

```bash
npm run build
```

Vite generates the production files inside the `dist/` directory.

To test the production build locally:

```bash
npm run preview
```

## 🎯 Project Goal

The goal of this project is to build a medicine tracking application while learning practical software development and DevOps concepts, including Git, GitHub, Jenkins, CI/CD, Docker, and cloud deployment.
